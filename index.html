Cómo Funciona Este Grid Inteligente

CSS Grid Mágico

.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(var(--grid-size), 1fr));
    grid-auto-rows: 250px;
    gap: 1.5rem;
    grid-auto-flow: dense;
}

.gallery-item.featured {
    grid-column: span 2;
    grid-row: span 2;
}

/* ⭐ auto-fit: Crea columnas automáticamente
   ⭐ minmax(): Tamaño flexible con límites
   ⭐ grid-auto-flow: dense; Rellena huecos automáticamente
   ⭐ 1fr: Usa fracciones del espacio disponible */

Auto-fit Inteligente

Calcula automáticamente el número óptimo de columnas basándose en el espacio disponible.

Minmax Flexible

Define límites flexibles: mínimo 200px, máximo 1fr. Se adapta a cualquier contenedor.

Grid Dense

Rellena huecos automáticamente con elementos más pequeños, optimizando el espacio.

Responsive Nativo

Sin media queries complejas. Se adapta fluidamente a móviles, tablets y escritorio.

Comparación: Grid vs Flexbox

CSS Grid

  • Bidimensional (filas y columnas)
  • Control preciso de posiciones
  • Auto-fit y Auto-fill nativos
  • Perfecto para layouts complejos

Flexbox

  • Unidimensional (fila o columna)
  • Alineación sencilla
  • Ideal para componentes
  • Mejor para contenidos lineales
